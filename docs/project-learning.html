Project Learning

项目不是课程结束后的装饰，而是整合知识、协作、制作、反馈与表达的学习过程。

本页从三个层面展开，帮助家庭和学生快速理解这一主题如何进入课程、关系与日常校园生活。

01

问题定义

问题定义，从真实学习中发生。

学生先理解受众、情境与限制，把宽泛主题转化为可以研究和行动的问题。

02

原型迭代

原型迭代，从真实学习中发生。

草图、模型、实验和用户反馈帮助作品不断修正，失败被转化为下一轮迭代的信息。

03

公开表达

公开表达，从真实学习中发生。

项目通过展览、演示、答辩或真实交付面向受众，学生需要解释证据、选择与影响。

“当作品需要面对真实受众，学生会自然地对质量、表达和责任提出更高要求。”

Qingyun Academy · Shenzhen
